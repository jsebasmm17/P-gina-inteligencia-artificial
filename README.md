# Cuaderno Neuro — Portafolio académico

Sitio estático creado con HTML, CSS y JavaScript puro, preparado para GitHub Pages.

## Contenido
- Inicio y presentación del propósito del sitio
- Sobre mí y formación
- Intereses académicos
- Proyectos en desarrollo
- Producción académica
- Actividades formativas
- Recursos externos
- Contacto configurable
- Navegación adaptable a móviles y medidas básicas de accesibilidad

## Personalización antes de publicar
1. Abre `index.html` y reemplaza el nombre del sitio si lo deseas.
2. Añade tu correo institucional o perfil académico en la sección Contacto. No publiques información personal que no quieras hacer pública.
3. Revisa la descripción personal y la formación para que reflejen exactamente tu situación.
4. Añade recursos y proyectos solo cuando puedas verificarlos; incluye referencias para contenido científico y reconoce los derechos de autor de imágenes y figuras.
5. Revisa todos los enlaces y prueba el sitio en móvil.

## Publicar en GitHub Pages
1. Crea un repositorio público en GitHub, por ejemplo `cuaderno-neuro`.
2. Sube `index.html`, `styles.css`, `script.js` y `README.md` a la raíz del repositorio.
3. En el repositorio, abre **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/(root)`, luego pulsa **Save**.
6. Espera a que GitHub Pages publique el sitio. La URL suele ser `https://TU-USUARIO.github.io/cuaderno-neuro/`.

Si el repositorio se llama `TU-USUARIO.github.io`, la URL normalmente será `https://TU-USUARIO.github.io/`.

## Nota ética
El sitio es un portafolio educativo de una persona en formación. No constituye consejo médico ni sustituye la valoración profesional. No incluyas datos identificables de pacientes ni material protegido sin autorización.
